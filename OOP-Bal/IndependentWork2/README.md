## Проблеми процедурної версії
1. Дані одного товару знаходяться у різних масивах.
2. Усі масиви повинні мати однакову довжину.
3. Якщо потрібно додати нову інформацію про товар, треба створювати
   ще один масив.
4. Для роботи з кошиком потрібно передавати кілька масивів у методи.

## Порівняння підходів
У процедурній версії я працювала з масивами та окремими методами.
В об'єктній версії я створила клас Product для товару і клас Cart
для кошика.
Основні відмінності:
1. У процедурній версії дані товарів зберігаються в окремих масивах,
   а в об'єктній — у класі Product.
2. У процедурній версії для роботи з кошиком потрібно передавати
   кілька масивів, а в об'єктній використовується один об'єкт Cart.
3. В об'єктній версії легше додати нову властивість товару, тому що
   її можна додати до класу Product.
4. Нові операції з кошиком можна додавати як методи класу Cart.
