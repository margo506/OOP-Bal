# Лабораторна №9
## Тема: HashSet/Queue/Stack: практичні сценарії.
### Мета: Навчитися використовувати спеціалізовані колекції HashSet<T>, Queue<T>, Stack<T> для розв’язання практичних задач, зрозуміти їхні особливості та сценарії застосування.
У лабораторній роботі було створено програму «Система управління завданнями», у якій використано три спеціалізовані колекції. За допомогою HashSet реалізовано
зберігання унікальних тегів із можливістю додавання, видалення та перевірки наявності. Колекцію Queue використано для створення черги завдань, у якій вони 
виконуються в порядку додавання. Для зберігання історії виконаних завдань використано Stack, що дозволяє скасувати останнє виконане завдання та повернути його 
до черги.
