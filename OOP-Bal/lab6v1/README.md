# Лабораторна №6
## Тема: Абстрактні класи та інтерфейси. Контракти та реалізації.
### Мета: Навчитися створювати та використовувати абстрактні класи та інтерфейси для визначення контрактів та реалізації спільної логіки, а також розуміти критерії вибору між ними.
У лабораторній роботі було реалізовано інтерфейс IRepository<T> та класи InMemoryUserRepository і FileUserRepository для роботи з користувачами. 
Було розглянуто використання інтерфейсів для визначення спільних методів, а також абстрактного класу DocumentProcessor для обробки документів. 
Було створено класи TextDocumentProcessor та XmlDocumentProcessor, які реалізують власну обробку документів. Для демонстрації поліморфізму було 
створено колекції об'єктів типу інтерфейсу та абстрактного класу, через які виконувалися операції з користувачами та обробка документів.
