# Лабораторна №7
## Тема: Узагальнені типи (Generics). IRepository з where-обмеженнями та тестами.
### Мета: Навчитися створювати узагальнені інтерфейси та класи, застосовувати where-обмеження для типів-параметрів, а також розробляти юніт-тести для перевірки коректності узагальнених реалізацій.
У лабораторній роботі було створено узагальнений інтерфейс IRepository<T> з обмеженням where T : IEntity та його реалізацію InMemoryRepository<T> 
для зберігання даних у пам'яті. Було створено інтерфейс IEntity з властивістю Id та клас Product, який містить назву товару, ціну і кількість на складі.
У класі InMemoryRepository<T> реалізовано методи додавання, отримання, оновлення та видалення товарів. Також було написано 8 юніт-тестів за допомогою xUnit 
для перевірки роботи всіх методів, зокрема обробки випадків із неіснуючими ідентифікаторами.
