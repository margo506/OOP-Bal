Створено клас FileLogger, який реалізує інтерфейс IDisposable.
Клас має:
- приватні поля _filePath, _isFileOpen та _disposed;
- публічні властивості FilePath та IsFileOpen;
- конструктор, який імітує відкриття файлу;
- метод Log() для виведення повідомлень;
- метод Dispose() для звільнення ресурсу;
- метод Dispose(bool disposing);
- деструктор ~FileLogger().
## Висновок
У першому сценарії using автоматично викликає Dispose() після завершення роботи з об'єктом. У другому сценарії Dispose() викликається вручну, тому програміст сам визначає момент звільнення ресурсу. У третьому сценарії Dispose() не викликається, тому ресурс звільняється під час роботи деструктора після GC.Collect() та GC.WaitForPendingFinalizers().
