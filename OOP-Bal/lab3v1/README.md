# Лабораторна робота №3
## Тема: Життєвий цикл об’єкта та керування ресурсами.
### Мета: Поглибити розуміння життєвого циклу об’єкта в C#, навчитися працювати з некерованими ресурсами, реалізувати інтерфейс IDisposable та патерн Dispose.
У лабораторній роботі було реалізовано клас FileLogger, який використовує інтерфейс IDisposable та патерн Dispose.
Було розглянуто три способи звільнення ресурсу: автоматичний виклик Dispose() за допомогою using, явний виклик Dispose() 
та звільнення ресурсу через деструктор під час роботи збирача сміття. Найзручнішим і безпечним способом є використання using,
оскільки Dispose() викликається автоматично після завершення роботи з ресурсом.
