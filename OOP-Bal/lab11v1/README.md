# Лабораторна №11
## Тема: LINQ: SelectMany, пагінація й custom extensions.
### Мета: Навчитися використовувати оператор SelectMany для роботи з вкладеними колекціями, реалізовувати пагінацію даних за допомогою LINQ, а також створювати власні методи розширення для IEnumerable<T>.
У лабораторній роботі було створено програму, у якій використано три класи з вкладеними колекціями: Author (Id, Name, Books), Book (Id, Title, Chapters) 
та Chapter (Id, Title, PageCount). Колекції заповнено тестовими даними: 4 автори, 12 книг і 36 розділів. За допомогою SelectMany (у синтаксисі методів і запитів) 
усі розділи всіх книг усіх авторів зібрано в один список із 36 елементів. Пагінацію реалізовано через Skip і Take: 12 книг виведено по 3 на сторінку, 
всього 4 сторінки. Також створено власний метод розширення TotalPages() для IEnumerable<Chapter>, який підсумовує кількість сторінок у розділах: для всіх
розділів він повернув 925 сторінок, для книги «Clean Code» 75 сторінок, а для розділів довших за 30 сторінок (після Where) 279 сторінок.

Контрольні запитання
1. SelectMany розгортає вкладені колекції в одну плоску послідовність, а Select перетворює кожен елемент рівно в один елемент. Наприклад, Select по авторах поверне 4 списки книг, а SelectMany один список із 12 книг.
2. Методами Skip і Take: Skip пропускає елементи попередніх сторінок ((номер сторінки − 1) × розмір сторінки), Take бере елементи поточної сторінки. Кількість сторінок обчислюється діленням кількості елементів на розмір сторінки із заокругленням угору.
3. Методи розширення - це статичні методи у статичному класі з ключовим словом this перед першим параметром, які додають нові методи до існуючого типу без зміни його коду. Усі оператори LINQ (Where, Select, SelectMany, Skip, Take) самі є методами розширення для IEnumerable<T>, тому власні методи можна поєднувати з ними в одному ланцюжку викликів.
4. Метод TotalPages() для IEnumerable<Chapter> підсумовує PageCount усіх розділів і працює з будь-якою послідовністю розділів: з усіма, з розділами однієї книги чи після фільтрації через Where.
