# Лабораторна №4
## Тема:Наслідування. Ключові слова base, override, virtual. Приховування членів (new).
### Мета:Навчитися створювати ієрархії класів, використовувати ключові слова base, virtual, override для реалізації поліморфізму, а також розуміти відмінності між override та приховуванням членів за допомогою new.
У лабораторній роботі було реалізовано ієрархію класів Employee, Manager та Director. Було розглянуто використання наслідування, 
виклик конструкторів базових класів за допомогою base, перевизначення віртуальних методів за допомогою override та реалізацію поліморфізму.
Також було продемонстровано різницю між override та new на прикладі методу GetRole(), який повертає різні результати залежно від типу посилання на об’єкт.
