# Лабораторна №12
## Тема: Обробка IO/мережевих помилок та патерн Retry.
### Мета: Навчитися обробляти типові помилки вводу/виводу та мережеві помилки за допомогою блоків try-catch-finally, а також реалізувати патерн Retry для підвищення відмовостійкості застосунків.
У лабораторній роботі було створено консольний проєкт lab18v1 із трьома класами: FileProcessor, NetworkClient та RetryHelper. У класі FileProcessor реалізовано
метод ReadFile(), який імітує читання файлу та перші дві спроби завершує помилкою FileNotFoundException, після чого повертає успішний результат. Клас NetworkClient
містить метод DownloadData(), який перші три рази викликає HttpRequestException, а на четверту спробу успішно завантажує дані. У класі RetryHelper створено
узагальнений метод ExecuteWithRetry<T>, який повторює виконання операції, перевіряє тип винятку за допомогою shouldRetry та використовує експоненційну затримку
між спробами. У методі Main перевірено роботу обох класів, а також вибіркову обробку винятків: для IOException повторні спроби не виконувалися. У результаті 
читання файлу завершилося успішно з третьої спроби, а завантаження мережевих даних — з четвертої.
