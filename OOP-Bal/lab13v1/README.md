# Лабораторна №13
## Тема: Власні винятки та патерн Result.
### Мета: Навчитися створювати власні типи винятків для специфічних помилок, а також реалізовувати патерн Result для більш контрольованої обробки помилок без використання винятків у нормальних сценаріях невдачі.
У лабораторній роботі було створено консольний проєкт із трьома класами: InsufficientFundsException, Result<T> та AccountService. Власний виняток
InsufficientFundsException містить властивості RequestedAmount і CurrentBalance та використовується під час спроби зняти суму, яка перевищує залишок на рахунку.
У класі Result<T> реалізовано властивості IsSuccess, Value та Error, а також методи Success() і Failure() для повернення результату операції. Клас AccountService
містить методи Withdraw() для зняття коштів і Deposit() для поповнення рахунку. У методі Main перевірено обидва способи обробки помилок: недостатню кількість коштів 
оброблено через try-catch, а неправильну суму поповнення — за допомогою Result.Failure та перевірки IsSuccess і Error. Також перевірено успішне зняття та поповнення
коштів.
