# Лабораторна №8
## Тема: Делегати й лямбда-вирази у практиці колекцій: CollectionHelper<T>.
### Мета: Навчитися передавати поведінку як параметр через делегати Func, Action, Predicate, будувати на цій основі універсальні операції над колекціями та використовувати лямбда-вирази у практиці ООП.
У лабораторній роботі було створено статичний узагальнений клас CollectionHelper<T> з методом FindMaxBy<TKey>, який приймає колекцію та делегат Func<T, TKey> 
і повертає елемент із максимальним ключем. Пошук максимуму реалізовано власним кодом без LINQ, а для порожньої колекції передбачено виняток. У методі Main роботу
методу продемонстровано на List<int>, List<string> та List<Product> за допомогою лямбда-виразів: знайдено найбільше число, найдовше слово і найдорожчий товар.
